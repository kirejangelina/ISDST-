3. Сценарий конфликта и его разрешение
При слиянии ветки branch-one в master (команда git merge branch-one) возник конфликт в файле generator.py, так как обе ветки правили одну и ту же строку.

Фрагмент конфликтных маркеров в файле:

python
<<<<<<< HEAD
    return f"--- БЕЙДЖ УЧАСТНИКА ---\nИмя: {name}\nРоль: {role}\nСПАСИБО ЗА УЧАСТИЕ!"
=======
    return f"--- БЕЙДЖ УЧАСТНИКА ---\nИмя: {name}\nРоль: {role}\nСпасибо за участие! 🚀"
>>>>>>> branch-one
Как разрешили: Конфликт разрешен вручную в редакторе. Маркеры были удалены, оставлен объединенный вариант (заглавные буквы + эмодзи). Изменения зафиксированы коммитом:

bash
git add generator.py
git commit -m "Разрешил конфликт: объединил заглавные буквы и эмодзи"
