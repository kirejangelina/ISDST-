# Техническая документация

## Архитектура
Приложение построено по принципу REST API. 
- **Frontend:** Отображает ленту и избранное.
- **Backend (API):** Обрабатывает запросы, фильтрует новости, работает с базой данных.
- **Источники новостей:** Внешние API (RSS-ленты или сторонние сервисы), откуда агрегатор забирает данные по расписанию.
