# Руководство пользователя

Это приложение собирает новости из разных источников и показывает их в удобной ленте.

## Как начать работу
1. Откройте приложение в браузере.
2. Вы увидите главную страницу (ленту новостей), где уже загружены последние события.
3. Прокрутите вниз, чтобы подгрузить больше новостей (пагинация).

## Основные сценарии

### 1. Чтение ленты
Лента обновляется автоматически. Каждая новость содержит:
- Заголовок
- Краткое описание
- Источник (например, "РИА Новости", "Хабр")
- Кнопку "Подробнее" для перехода на полную статью

### 2. Сохранение в избранное
Если новость вам понравилась, нажмите на иконку "Звездочка" (⭐) под новостью. Она сохранится в ваш личный список "Избранное". 
Чтобы посмотреть избранное, нажмите на кнопку "Мои закладки" в верхнем меню.

## FAQ (Часто задаваемые вопросы)
**Почему новости не обновляются?**
Проверьте подключение к интернету. Если сеть стабильна, возможно, источники временно недоступны. Попробуйте обновить страницу позже.

**Как удалить новость из избранного?**
Зайдите в раздел "Избранное" и нажмите на звездочку еще раз. Новость исчезнет из списка.

**Нужно ли регистрироваться?**
Для чтения ленты регистрация не требуется. Однако для сохранения избранного и настройки персональной ленты нужен аккаунт.
